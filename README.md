# PT INSAI Indonesia — Website

Static website. No build step required — upload the contents of this folder to any web host.

## Files
- index.html  → entry point
- styles.css  → all styling
- app.js      → application (precompiled, no Babel needed)
- img/        → all imagery

Upload the folder contents to your host's web root (index.html must be at the root).
React is loaded from the unpkg CDN; fonts load from CDNs.
